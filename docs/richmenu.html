Rich Menu 圖片產生器

LINE 官方帳號的圖文選單要上傳一張圖。這頁會照 app 的配色畫一張 2500 × 843（compact 尺寸）的 PNG，按下面的按鈕就能存檔。

檔名：richmenu-shift.png ・ 尺寸 2500×843 ・ 1 個按鈕（整條）

接著在 LINE 官方帳號後台設定

  1. LINE Official Account Manager → 主頁 → 圖文選單 → 建立
  2. 版型選 大（compact）的「1 格」（整條一個區塊）
  3. 背景圖片上傳這張 PNG
  4. 動作選 連結，網址填 https://liff.line.me/{LIFF_ID}
  5. 選單列顯示文字：排班　／　預設顯示：開啟
  6. 套用期間設成長期，然後儲存
